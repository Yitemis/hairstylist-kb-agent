# Figma 提示词 (前端新功能)

> 风格: 紫色 #6366f1 primary, dark sidebar #1e293b, 圆角 10/14px, Inter 字体, mobile-first iPhone 14 (393×852)
> 已有页面参考: LoginPage, ChatPage, AdminLayout
> 输出格式: 一段连贯中文描述 (与 figma MakeKit 风格一致)

---

## 1. 多模态聊天输入框 (升级 ChatPage)

在已有 ChatPage 底部输入区加图片上传。底部输入栏高度保持 56px，左侧放两个圆形图标按钮 (相机紫色 #6366f1 + 相册灰色 #f1f5f9)，中间 14px 圆角输入框 placeholder "说点什么...可发图片"，右侧紫色 #6366f1 圆形发送按钮 (32px)。选中图片后在输入栏上方显示横向滚动缩略图条 (最多 3 张, 64×64 圆角 8px, 右上角小红 X 删除)。当有图片时输入框左侧显示 "图片模式" 紫色 chip 标签。AI 回复气泡内可以包含 inline 图片预览 (圆角 12px)。整体保持 mobile-first 393×852，跟现有 ChatPage 配色 (灰底 #f1f5f9 AI 气泡 + 紫底 #6366f1 用户气泡) 完全一致。

## 2. HITL 人在回路确认卡片

通用确认弹窗，居中显示，半透明黑遮罩 rgba(0,0,0,0.5)。卡片 400×auto 宽，白底圆角 14px，柔和阴影 0 10px 30px rgba(0,0,0,0.08)。顶部居中 48×48 圆形橙色 #f59e0b 背景，中心白色警告三角图标。标题 "需要您的确认" 18px 居中加粗 #1e293b。副标题 "您确定要 [操作] 吗？" 14px #64748b 居中，最多 2 行省略号。底部左右两个按钮等宽，左侧灰色 #f1f5f9 文字 #64748b "取消"，右侧橙色 #f59e0b 文字白色 "确认"。**确认按钮 5 秒倒计时** (圆形进度环从 100% 转到 0%)，倒计时结束才可点击，避免误操作。底部小字 "此操作将被系统记录审计" 居中灰色 12px。背景动效: 弹窗从下方 20px 滑入 200ms。

## 3. 我的记忆管理页 (C 端新页面)

移动端页面 "我的记忆"，顶部 nav: 左返回箭头 (20×20 SVG)，中 "我的记忆" 16px 加粗 #1e293b，右信息图标 (20×20 灰色 #94a3b8)。Body 区域是 memory item 列表，每条 item 是一张白色卡片 (圆角 14px, padding 16px, margin 12px, 阴影 0 1px 3px)。卡片内: 左侧 40×40 紫色 #6366f1 圆形背景 + 白色分类图标 (人物/地点/物品三选一)，中间 类别名 14px 加粗 + 内容 13px #64748b (最多 1 行)，下方 8px 高进度条 (绿色 >0.7, 黄色 0.4-0.7, 红色 <0.4) 显示置信度，右侧 24×24 删除图标 (灰色 hover 变红 #ef4444)。空状态: 居中 80×80 紫色 #6366f1 透明度 10% 的圆形 + 内置 SVG 大脑图标，下方 16px "AI 还没记住你的偏好" 灰色 #64748b，副标题 13px "多跟 AI 对话，它会学习你的喜好"。底部固定一个红色文字按钮 "清空全部记忆"，无背景。**严禁** 自动调用 AI 生成，UI 静态。

## 4. RAG 评估 dashboard (Admin 新页)

桌面端 1440×900 admin 页面 "RAG 质量评估"。顶部 4 个并排 stat card (宽 320 高 120, 间距 24): Recall@5 / MRR / Hit Rate / NDCG@5，每个卡片大数字 36px 加粗 #1e293b + 副标题 13px #64748b，**卡片右上角小绿色 ↑ 箭头** 显示相对上次评估的百分比变化 (绿色 / 红色)。中部 Line Chart (高度 240, 16px padding, 紫色 #6366f1 主色) 显示最近 7 天的 recall 趋势，X 轴日期 Y 轴 0-1 数值。下方 Table (占满剩余高度): 列 = Query (左对齐 35%) | Category (chip 12px) | Recall@5 (居中 + 颜色) | MRR (居中 + 颜色) | Latency (居中 ms)，15px 行高，hover 整行变 #f8fafc。**根据分数染色**: ≥0.7 绿色 #10b981, 0.4-0.7 黄色 #f59e0b, <0.4 红色 #ef4444。顶部右上角下拉 "按类别筛选" (knowledge/booking/multimodal/casual) + 紫色 "运行新评估" 按钮 (点击后变 loading spinner 2 秒)。点击行可展开显示该 query 检索到的 docs 列表 (缩略 markdown 渲染)。**整页 desktop 布局，移动端不考虑**。

桌面端 1440×900 admin 页面 "数据归档管理"。顶部 3 个 stat card: 总聊天消息数 / 6 月以上未归档数 / 本月已节省空间 (MB)，每张卡 320×120 大数字 36px。下方一张"操作面板"卡片: 左 16px 标题 "上次归档" + 副标题 "2026-08-05 03:00:00 (3 天前, 自动化执行)"，右主按钮紫色 "立即归档" (点击变 loading 8 秒，弹 toast "已归档 X 条消息 / Y 条订单")。中部警告横幅 (背景 #fef3c7, padding 12×16, 圆角 8px): 黄色 #f59e0b 图标 + "建议每周日凌晨 03:00 自动归档" 提示文字。下方 Table 显示历史归档记录 (列: 时间 / 类型 (chat/order) / 数量 / 节省空间 / 耗时 / 状态 (success/failed chip))，10 行分页，底部分页器。**桌面端布局**，顶部对齐 admin 现有管理页风格 (深色 sidebar + 浅色内容区)。左对齐 #1e293b 标题 24px 加粗。

## 6. Prometheus 实时监控 dashboard (Admin 新页)

桌面端 1440×900 admin 页面 "实时监控"。顶部 4 个 stat card (高度 140, padding 24, 圆角 14px): "Chat QPS" (绿色 ↑ 12%)、"P99 延迟" (黄色 ⚠ 2.3s)、"错误率" (红色 ↑ 0.5%)、"缓存命中率" (绿色 ↑ 85%)，每个卡片大数字 42px + 副标题 14px + 右下角小型 sparkline (7 个数据点 60×30 像素)。中部并排 2 个 chart (各占一半宽 240px 高): 左 "Chat QPS over time" Line Chart (紫色 5min 窗口)，右 "RAG 检索延迟" Bar Chart (按 p50/p90/p99 三色柱)。下方 3 个并排 list card: "Top 5 慢 query" / "Top 5 错误端点" / "活跃 session 数" (每个 list card 列出 5 行带数字 + endpoint)。颜色规则: 健康绿色 #10b981, 警告黄色 #f59e0b (阈值 80%), 危险红色 #ef4444 (阈值 95%)。顶部右上角 "导出" + "刷新" 按钮 + "**每 5 秒自动刷新**" 倒计时器 (10px 字 灰色)。**纯监控用途，不含 AI 生成**。

## 7. SSE 流式聊天体验 (升级 ChatPage)

升级已有 ChatPage 接入 SSE 流式输出。用户点发送后, 紫色 "发送" 按钮立即变成 "停止" 按钮 (红色 #ef4444 圆形, 中心 ⏸ 暂停图标)。AI 回复区逐字 (token) 流式出现, 每个字符淡入 30ms, 末尾有"打字中"动画 (3 个圆点脉动)。流式过程中右上角显示 "▌ AI 正在思考..." 小提示词 (灰色 #94a3b8 斜体)。**AI 思考过程** 用淡灰色 (背景 #f8fafc) 斜体字显示在正式回答之前, 例如 "我需要查询一下染发相关的知识..."。流式结束后: 回复底部显示 "已生成完 · 234 token · 1.2s" 灰色 11px 统计信息。如果中途用户点 "停止" → 弹 "生成已中断" toast。如果流式报错 → 显示红色错误卡片 + "重试" 按钮。整体保持 mobile-first 393×852, 跟现有 ChatPage 配色和布局 (用户右紫气泡, AI 左灰气泡) 完全一致, 但 AI 气泡内容是逐字追加而不是一次性渲染。
